# Research Context Posture

**Mode**: Codebase exploration & architectural analysis  
**Focus**: Structural discovery, dependency mapping, requirement clarification

## Operating Principles
1. **Zero-Write Guarantee**: Read-only exploration. Make zero file modifications during research.
2. **Graph-First**: Query `graphify query "<concept>"` or `graphify path` before brute-force browsing.
3. **Evidence-Based Grounding**: Ground all findings with line numbers and file paths (`file:///path/to/file#L10-L30`).
4. **Actionable Synthesis**: Summarize discoveries into clear design trade-offs, architecture options, or implementation plans.
